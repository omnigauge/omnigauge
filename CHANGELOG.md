# Changelog

All notable changes to OmniGauge, newest first. Versions are the ones on PyPI.

## 1.0.4 — 2026-08-20

- `omnigauge --update`: upgrade with the same tool that installed it (pipx upgrade /
  pip install --upgrade / git pull + install.sh for a clone, detected from the
  interpreter and the file's own directory), then clear and restart, so the first
  thing on screen is the new board with the new version. Listed in --help; the
  board's own update-on-disk restart already covered a running --watch.

## 1.0.3 — 2026-08-18

- Two READMEs from one source: GitHub keeps the text board; PyPI renders
  `README.pypi.md`, generated by `ops/gen_readme_pypi.py` with a rendering of the
  board in its place (registry pages cannot carry our font, and box-drawing glyphs
  from a fallback face draw dashed). A test refuses drift between the two.
- `assets/readme-board.png` — the board drawn from the README's own text
  (`ops/render_readme_board.py`).

## 1.0.2 — 2026-08-18

- README: the board as a rendered image, the text kept alongside.

## 1.0.1 — 2026-08-17

- README: images and links absolute, so PyPI renders them. Packaging only.

## 1.0 — 2026-08-17

- First release on PyPI: `pipx install omnigauge` (or `pip install omnigauge`).
- The single file and every provider mirror travel inside the wheel, side by side,
  so the installed command finds `providers/` exactly where the file looks; a
  mirror that is not shipped would silently fall back to the built-in, and
  `tests/test_packaging.py` refuses that. `./install.sh` remains for source.
- Everything the site describes: plan quota, token volume, burn rate and
  time-to-reset, `--check` for cron, the optional spend panel; five agent
  providers and five API sources.
